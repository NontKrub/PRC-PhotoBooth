# v1.4.3 Release Hardening Invariants

These are release invariants. A helper-level test does not satisfy an invariant
unless it exercises the production path.

- No visible authoritative state change occurs before required durable state is committed.
- A manifest never points to content that an uncommitted replacement can overwrite.
- Workspace files are not deleted while a job can still read or write them.
- A stale in-memory manifest never overwrites a newer durable manifest.
- Socket failure detection, invalidation, and reconnect scheduling do not require MainActor progress.
- A client action mutates only the exact authoritative state occurrence for which it was issued.
- Only one logical physical print operation is active at a time.
- A print timeout is unknown, not proof that AppKit ended the operation.
- Healthy asset backpressure does not close a healthy control connection.
- Failed transactions restore the prior working state or enter an explicit recoverable error state.
- Guest capture attempt boundaries are strictly validated; stale media from previous sessions is never returned.
- Finalization transactions atomically link manifests to job bundles; failed job enqueueing never rolls manifest back to capturing.
- Guest QR codes never contain localhost, loopback, VM bridge, or tunnel interfaces.
- Concurrent HTTP connections from a single client cannot exhaust the local web server.

   - Added `preAuthTimedOut` diagnostic event and `preAuthWatchdogCancelsConnectionWhileMainActorBlocked` regression test in `Tests/NetworkRouteTests.swift`.

4. **A04: Pre-Auth Rate Limiting Hardening (P1 / Critical) — RESOLVED**

6. **A06: Guest Delivery Interface Resolution (P1 / Critical) — RESOLVED**

   - Refactored `LocalWebServer.lanIPAddress()` to use resolver.
   - Refactored `SessionQRCodePayloadResolver` to reject localhost/loopback and mark local delivery `.unavailable` when no routable interface exists.
   - Added test suite `Tests/GuestDeliveryEndpointResolverTests.swift` (9 passing tests) and updated `Tests/SessionQRCodePayloadResolverTests.swift`.

   - Rejects excess requests with 503 "Server busy".
   - Added regression test `perClientConnectionLimitThrottlesExcessRequests` in `Tests/LocalWebServerTests.swift`.
