# macOS Settings layout audit

## Findings

1. **The single-row segmented picker is the clipping source.** `SettingsSection` has eight categories, including the long “iPad & Network” and “Event Readiness” labels (`/Users/nont/my-project/PRC-PhotoBooth/Mac/UI/MacContentView.swift:110-120`). The picker renders every category in one `.segmented` control, with no wrapping or adaptive navigation (`/Users/nont/my-project/PRC-PhotoBooth/Mac/UI/MacContentView.swift:154-171`). Against `origin/fix/v1.4.2-stability-pairing`, v1.4.2 already had this same picker with seven categories (`Mac/UI/MacContentView.swift:102-108, 139-150` in that ref); v1.4.3 adds Event Readiness and routes it to the new `SoakTestSettingsView` (`/Users/nont/my-project/PRC-PhotoBooth/Mac/UI/MacContentView.swift:118, 228-250`; `/Users/nont/my-project/PRC-PhotoBooth/Mac/UI/SoakTestSettingsView.swift:5-85`). That eighth segment is the concrete regression trigger. At the 940-point minimum, the UI has no alternate layout when segment titles or localized text need more room.

2. **The fixed minimum creates the blank area.** `ProtectedSettingsView` applies `minWidth: 940, minHeight: 640` around both the PIN gate and unlocked Settings (`/Users/nont/my-project/PRC-PhotoBooth/Mac/MacApp.swift:29-46`). The gate itself is only 320 points wide (`/Users/nont/my-project/PRC-PhotoBooth/Mac/UI/PINGateView.swift:31-95`). After unlock, General is two compact groups (`/Users/nont/my-project/PRC-PhotoBooth/Mac/UI/MacContentView.swift:228-235, 746-768`); Camera, Display, and Security are also short single-group pages (`/Users/nont/my-project/PRC-PhotoBooth/Mac/UI/MacContentView.swift:266-302, 704-744, 844-872`). Their `ScrollView` fills the remaining window below the navigation row, leaving a large empty viewport (`/Users/nont/my-project/PRC-PhotoBooth/Mac/UI/MacContentView.swift:154-173`). The operator `WindowGroup` has a separate minimum at line 36 of `/Users/nont/my-project/PRC-PhotoBooth/Mac/UI/MacContentView.swift` (line 37 sets its locale); it is not the Settings scene’s sizing control.

3. **The selected operator language does not reach Settings, and section labels are not localized.** `operatorLocale` is applied to the operator window at `/Users/nont/my-project/PRC-PhotoBooth/Mac/UI/MacContentView.swift:36-37` and computed there at lines 98-104. `MacApp` creates the separate Settings scene without a locale environment (`/Users/nont/my-project/PRC-PhotoBooth/Mac/MacApp.swift:19-24`). In addition, the picker constructs labels with `Text(section.rawValue)` (`/Users/nont/my-project/PRC-PhotoBooth/Mac/UI/MacContentView.swift:156-159`), so its runtime `String` labels are displayed verbatim. “General,” “iPad & Network,” “Display,” “Cloud,” “Security,” and “Event Readiness” are absent as keys in both the current and HEAD `/Users/nont/my-project/PRC-PhotoBooth/Mac/Localizable.xcstrings`; “Camera” and “Printing” exist, but this picker still does not use localized keys. Several new Event Readiness labels are also absent, including “Event Readiness & Soak Testing,” “Retained soak diagnostics,” and “Start Event Readiness Soak Test?” (`/Users/nont/my-project/PRC-PhotoBooth/Mac/UI/SoakTestSettingsView.swift:73-85, 111-126`). `SettingsView` already reads `operatorLanguage` (`/Users/nont/my-project/PRC-PhotoBooth/Mac/UI/MacContentView.swift:142`) and declares `@Environment(\.locale)` at line 132, but does not use that environment value.

4. **All eight detail routes and the PIN/action ownership are already centralized and should remain in place.** The exhaustive section switch maps each category, including Event Readiness (`/Users/nont/my-project/PRC-PhotoBooth/Mac/UI/MacContentView.swift:228-250`). `ProtectedSettingsView` owns initial setup/verification, unlock, cancel, and re-lock after PIN reset (`/Users/nont/my-project/PRC-PhotoBooth/Mac/MacApp.swift:29-46`); Security calls `onResetPIN` only after the Keychain reset succeeds (`/Users/nont/my-project/PRC-PhotoBooth/Mac/UI/MacContentView.swift:844-872`). Keep `SettingsView`’s root sheets, forget confirmations, Keychain failure alert, printer refresh task, and scene-phase handling attached to the settings root (`/Users/nont/my-project/PRC-PhotoBooth/Mac/UI/MacContentView.swift:174-225`). The detail pages contain the current pairing, reconnect, diagnostics, event-folder, printing, cloud, and soak actions; retain their existing view bodies when changing navigation (network controls: `/Users/nont/my-project/PRC-PhotoBooth/Mac/UI/MacContentView.swift:304-702`).

## Recommended structure

- Replace the segmented picker with a macOS `NavigationSplitView`: a selectable `List` using `.sidebar` style on the leading side and the existing section switch in the detail column. Give the sidebar a min/ideal/max width around 180/200/240 points. The native split view can adapt its presentation when resized; keep the eight categories selectable without horizontal scrolling.
- Keep the detail pane as a **vertical-only** `ScrollView`. Place a localized section heading above the current detail view, then give the content `.frame(maxWidth: .infinity, alignment: .leading)` and the scroll/detail container `.frame(maxWidth: .infinity, maxHeight: .infinity, alignment: .topLeading)`. This keeps short pages at the top and lets Network and Event Readiness scroll naturally.
- Move the unlocked Settings minimum to the Settings content rather than applying 940×640 to both branches of `ProtectedSettingsView`. A starting minimum around **780×540 points** gives a 180–200-point sidebar and roughly 520 points for detail content, accommodating the current 300-point network pickers and 280-point cloud fields (`/Users/nont/my-project/PRC-PhotoBooth/Mac/UI/MacContentView.swift:339-398, 815-821`). Give the PIN branch its own compact minimum consistent with its 320-point content. Preserve macOS 15 as the deployment target (`/Users/nont/my-project/PRC-PhotoBooth/project.yml:6-9, 70`).
- Keep section identity separate from display text: use stable enum IDs plus `LocalizedStringKey` titles and SF Symbol `Label`s. Add English/Thai catalog entries and apply the same `operatorLanguage`-derived locale to the Settings scene, so changing the language in General updates the sidebar and details immediately. Do not use translated text as the selection ID.
- Retain visible text with each sidebar icon, native list selection/keyboard/VoiceOver behavior, an accessibility heading on the detail title, and stable accessibility identifiers for section rows. Keep every existing route and action listed above.
